# FoodScannerApp

"A web app that lets users scan or search food items and returns nutritional information."
🧩 Main Features:
Upload image of food or enter a food name
Display nutrition facts (calories, protein, fat, etc.)
Store search history
View previous scans
Tests using Playwright

/client (React)
/server (Java Spring Boot)
/db (DB schema)
/tests (Playwright tests)
